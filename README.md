## 怎麼操作

| 按鍵 | 作用 |
|---|---|
| `→` 或空白鍵 | 下一步／下一頁（有「點一下」的頁面會先一步一步出現，出完才翻頁） |
| `←` | 上一步／上一頁 |
| `O` | 所有頁面總覽 |
| `M` | 關掉／打開動畫 |
| `F` | 全螢幕 |

有「▶ 點一下」提示的頁面可以用滑鼠點；離開那一頁再回來，會回到還沒點的狀態，可以重新來一次。
